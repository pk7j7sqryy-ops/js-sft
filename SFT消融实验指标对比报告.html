清洗规则与计算口径

所有图表和表格共用同一套统计规则

数据清洗

  1. 逐指标独立清洗：不删除整行；某指标无效不影响同行其他指标。
  2. 剔除 0 值与空值：数值为 0 / 0.0、空字符串、空值、NaN 均不纳入统计（按本次要求）。
  3. 仅保留有效正值：可解析为数值、有限且严格大于 0 才计入均值。
  4. 不按 status 过滤：query_failed / evaluation_partial 记录只要指标为有效正值仍保留。
  5. 编码处理：所有 CSV 用 utf-8-sig 解析，兼容 BOM。

统计公式

均值 = 清洗后有效观测值之和 ÷ 有效观测数 n
绝对差值 = SFT 后均值 − SFT 前均值
相对变化 (%) = 绝对差值 ÷ SFT 前均值 × 100%
  • 每个实验的「前/后」均值按各自文件的有效观测直接合并求平均（等价于按 n 加权）。
  • 百分比以未四舍五入的原始均值计算；页面仅控制展示精度。
  • 属于逐指标、非配对均值比较；前后 n 可能不同，不解释为严格同题配对提升。
  • 「SFT 前」文件在各实验间 byte 级一致（共享基线），仅 01 使用旧评测集、05 仅 hold、03 缺 hold 后评估。

解读边界与数据质量提示

  • 实验 01 使用旧评测集（hold 20 + human 10），样本量与其余实验（hold 40 + human 20）不同，不可与 02–06 直接横向对比，仅作历史参考。
  • 实验 03 缺失 hold 后评估文件，仅 human 20 题前后对齐；其 before/after 已按 human-only 口径重新对齐（n 一致），但样本范围窄，结论需谨慎。
  • 实验 05 仅 hold 40 题（无 human），before/after 均为 hold-only，口径内部一致，但无法与其他实验的「hold+human」均值直接等同比较。
  • 实验 02/04/06 为完整标准评测集（hold 40 + human 20），三者间口径一致，是横向对比的主要依据。
  • 本报告 0 值按规则剔除、不计入均值；若 0 代表真实失败得分，此规则会改变均值，建议另报零值率/缺失率。
